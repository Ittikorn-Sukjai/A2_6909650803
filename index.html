2. What I Built

I have built a single-page Learning Portfolio website. The key components include a structured layout using Semantic HTML elements such as header, main, section, and footer, styled with a separate CSS file.

Client or Server: When opening this website directly from my own machine, there is only a Client (the web browser) involved. There is no web server running because the browser is simply reading a local file from the hard drive via the file:// protocol, rather than requesting data over a network via HTTP/HTTPS.

3. How I Built It

The development process consisted of the following key steps:

  1. Setting up the required project directory structure (HTML, CSS, and media folders).
  2. Drafting the content and structuring it using HTML5 semantic tags.
  3. Applying CSS to handle page layout, typography, and spacing.

I used Visual Studio Code as my primary code editor and referenced MDN Web Docs for HTML and CSS properties.

4. Reflection

  • Challenges faced: Organizing the layout and centering elements correctly was challenging at first. I handled this by reviewing CSS box model concepts and using margin properties effectively.
  • What I learned: Doing this assignment gave me a much clearer understanding of how HTML structures the content and how CSS controls the visual presentation independently.
  • Future improvements: If I were to continue developing this site, I would add CSS Flexbox or Grid for a more complex layout, and implement media queries to make the website responsive for mobile devices.
